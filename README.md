# Ваш Доктор 7.0 — оригинальная графика сохранена

В `index.html` восстановлен предоставленный оригинальный файл с десятками встроенных изображений и без замены дизайна.

- Телефоны клиники: [+7 (484) 220-05-40](tel:+74842200540), [+7 (991) 222-10-40](tel:+79912221040).
- Врачи: в процессе публикации рабочий процесс запрашивает публичные страницы `https://vash-doc.ru/specialists/` и сохраняет последний удачный каталог в `data/doctors.json`. Обновление запускается каждые 6 часов. При ошибках парсинга остаётся предыдущая версия.
- Расписание конкретного врача отображается только при наличии явно опубликованного графика на его странице. Достоверные свободные слоты и записи доступны только через медицинскую систему клиники и требуют отдельной авторизованной интеграции. В приложении есть переход на сайт для записи.
- PWA: открыть https://xuyebaniy.github.io/VD/ на iPhone Safari или Android Chrome и добавить на главный экран. Первое подключение требует интернет, после чего интерфейс и сохранённые данные доступны офлайн.
- В публичную демонстрацию нельзя вводить реальные медицинские данные детей.

Для публикации в GitHub: Settings → Pages → Source → GitHub Actions. Рабочий процесс: `.github/workflows/pages.yml`.
