# Ваш Доктор — мобильное приложение PWA

Устанавливаемая версия проекта для iPhone и Android: **https://xuyebaniy.github.io/VD/** (после включения GitHub Pages и успешного деплоя).

## Установка
- iPhone: откройте адрес в Safari → Поделиться → На экран «Домой».
- Android: откройте адрес в Chrome → меню → Установить приложение.
- При первом посещении нужен интернет. Затем оболочка и сохранённый справочник открываются офлайн. Внешняя запись, звонки, сайт клиники и серверные медицинские функции требуют подключения.

## Что реализовано
- Мобильный полноэкранный интерфейс и PWA с иконкой.
- Сервис-воркер с сохранением оболочки и справочника.
- Локальный каталог врачей из прототипа, помеченный как **не подтверждённый актуальный**. Обновление из сайта клиники не настроено.
- Кнопка звонка и переход на vash-doc.ru/record.php для реальной записи.
- Демонстрационный «Сад здоровья» — не медицинская карта; настоящие медицинские сведения сюда вводить нельзя.
- В браузере GitHub Pages нет доступа к авторизованному API Битрикс / MedWork. Для личных медицинских данных нужны отдельные безопасные backend, авторизация, согласия и согласованная интеграция.

## Публикация
1. В репозитории Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Слить Pull Request в main.
3. Открыть Actions → Publish VD mobile PWA → Run workflow (или дождаться запуска после merge).
4. Проверить адрес https://xuyebaniy.github.io/VD/ на телефоне.

GitHub Pages — публичный хостинг. Не размещайте там персональные сведения пациентов. Каталог в data/doctors.json — сохранённый список для работы офлайн, **не подтверждение текущего штатного состава**.

## Разработка
Статический сайт: index.html, pwa-extras.js, manifest.webmanifest, sw.js. Иконки 192 и 512 автоматически формируются из icons/apple-touch-icon.png в ходе публикации. Заглушки отсутствующих графических материалов встроены как SVG; для запуска необходимы оригинальные дизайнерские assets.
