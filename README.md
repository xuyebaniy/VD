# Ваш Доктор — действующее PWA клиники

Это **то же установленное приложение**: https://xuyebaniy.github.io/VD/ . Адрес, PWA manifest id, иконка на домашнем экране и первоначальный дизайн не менялись.

**Что получает пациент**
- Оригинальный дизайн версии 7.0 и все встроенные иллюстрации.
- 40 действующих публичных карточек врачей и 40 фотографий (по последней успешной синхронизации), локально упакованных в опубликованную сборку.
- Обновление каталога и фотографий по расписанию GitHub Actions каждые три часа. Список автоматически попадает внутрь index.html при сборке, чтобы приложение сразу показывало живой каталог без ожидания отдельного запроса.
- При возобновлении приложения каталог проверяется; есть дополнительная кнопка «Обновить» внизу списка.
- Настоящий виджет онлайн-записи Medihost, код 48196, из официального сайта https://vash-doc.ru/record.php встроен во внутренний раздел «Запись» (booking-widget.html). При недоступности виджета есть официальный запасной переход. Для бронирования необходим интернет.
- Кнопка быстрого звонка на контактный центр.

**Сообщения в Telegram**
В приложении подготовлена форма «Написать в клинику» с проверкой готовности серверного обработчика. Пока сервер не подключён, **форма недоступна и никакого ложного подтверждения отправки нет**. Для запуска нужен бот, закрытая группа операторов и установка PHP на vash-doc.ru. Инструкция в integration/bitrix-telegram/INSTALL.md. Публичный канал https://t.me/vashdoktr нельзя использовать как получателя сообщений, содержащих личные или медицинские данные пациентов.

**Важно**
Данные о свободных часах и подтверждение записи предоставляются внешней действующей системой Medihost. Они не создаются скриптом искусственно. Сценарии с личными медицинскими данными требуют отдельной защищённой интеграции с системой клиники; браузерная PWA на публичном GitHub Pages не является таким хранилищем.

**Разработка и проверка**
- scripts/sync_doctors.py извлекает карточки и реальные изображения из атрибутов data-src сайта, сохраняет фото WebP без обрезания лица и кадров.
- scripts/embed_doctors.py вставляет только проверенный публичный каталог в оригинальный index.html на этапе сборки.
- .github/workflows/pages.yml запускает синхронизацию, сборку и публикацию.
- После обновления закройте установленное приложение и откройте снова с интернетом — переустановка не нужна.
