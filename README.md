# Ваш Доктор — PWA (автономный запуск)

Приложение открывается по обычной ссылке, ставится на смартфон как приложение (иконка на экране, без адресной строки),
работает без интернета (показывает последние сохранённые данные) и **само обновляет врачей и часы работы с vash-doc.ru каждые 6 часов**.
Кнопка «Позвонить» везде ведёт на **+7 (484) 394-00-03**.

## Публикация бесплатно: GitHub Pages (≈10 минут, один раз)

1. Зарегистрируйтесь на github.com → **New repository** → имя, например `vash-doctor-app`, тип **Public** → Create.
2. В пустом репозитории: **uploading an existing file** → перетащите ВСЁ содержимое этой папки (кроме скрытой `.github`) → Commit.
3. **Add file → Create new file**. В поле имени впишите `.github/workflows/site.yml` (слэши создадут папки) и вставьте содержимое файла `site.yml` из комплекта → Commit.
4. **Settings → Pages → Source: GitHub Actions**.
5. **Actions → «Обновить врачей и опубликовать приложение» → Run workflow**. Через 1–2 минуты в Settings → Pages появится адрес
   `https://ВАШ-ЛОГИН.github.io/vash-doctor-app/` — это и есть ссылка для друзей. Дальше всё работает само.

## Как поставить на телефон
* **iPhone:** открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить».
* **Android:** открыть в Chrome → кнопка «Установить» внизу экрана (или меню ⋮ → «Установить приложение»).

## Что обновляется автоматически
`scripts/scrape.py` читает https://vash-doc.ru/specialists/ (все страницы), страницы врачей и /contacts/: ФИО, специальность, фото, расписание (если оно есть на странице врача) и часы работы.
Если сайт изменил вёрстку и данных вдруг мало, прошлая версия не затирается — приложение продолжает показывать последние хорошие данные.
Запустить обновление немедленно: Actions → Run workflow.

## Где что менять
* Телефон, адрес — `pwa-extras.js` (вверху) и `data/doctors.json` → `clinic`.
* Иконки — папка `icons/` (192, 512, maskable, apple-touch).
* Интервал обновления — `cron` в `.github/workflows/site.yml`.

## Важно
Это публичный сайт: **не вводите в «Саде здоровья» и «Семье» реальные сведения о здоровье детей** — там демонстрационный режим без сервера.
Боевой дневник работает только на домене клиники вместе с Битрикс-API (см. руководство PWA 7.0).
