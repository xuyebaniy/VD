# Сообщения PWA -> Telegram: инструкция подключения

Готовая страница PWA находится в pwa-updates.js. При отсутствии серверной интеграции она сообщает, что отправка недоступна, и предлагает позвонить. Никаких ложных подтверждений доставки нет.

Для включения необходимо:
1. Создать закрытую группу операторов Telegram. Ссылка https://t.me/vashdoktr не подходит как конечный адрес для пациентских сообщений, если это публичный канал: подписчики смогут увидеть сообщения.
2. Создать бота через @BotFather, добавить его в закрытую супергруппу с правом отправлять сообщения и получить chat ID типа -1001234567890.
3. Разместить PHP-файл telegram-feedback.php на хостинге vash-doc.ru по пути /local/api/vd-pwa/v1/telegram-feedback.php. GitHub Pages не умеет запускать PHP.
4. Задать только на сервере окружение VD_TG_BOT_TOKEN и VD_TG_PRIVATE_CHAT_ID. Секреты нельзя помещать в GitHub или браузерный код.
5. Убедиться, что есть HTTPS, PHP curl и mbstring, а GET с ?health=1 возвращает {"ok":true,"ready":true}.
6. Отправить тестовое организационное сообщение без данных пациентов; проверить его поступление в закрытую группу.

Ограничение: это одностороннее уведомление операторов, не полноценный двусторонний чат. Для медицинских сведений, диагнозов, анализов, документов и личного кабинета пациента нужен защищённый канал связи с учётом врачебной тайны и персональных данных. В публичный Telegram-канал такие сообщения автоматически не отправлять.

Пока бот, доступ к хостингу и закрытый chat ID не предоставлены, интеграция только подготовлена и не активна.
